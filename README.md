# Case Studies

Business, strategy and product work by **Shubham Tanna**: the analysis behind the slides. Each folder has a README with the answer first, the source deck or model, and a `portfolio/` folder holding the data behind every chart, with `facts.md` tracing each number to its source.

| Case | The answer | Evidence |
|---|---|---|
| [Code1o1](code1o1/) | Co-founded a coding academy: 14 paying clients, about ₹2.6 lakh revenue, ₹0 on ads. Trust converts, reach doesn't: about 1% of cold calls became clients, every home visit did. | Founders' records, course catalogue |
| [Aur Sunao](aur-sunao/) | The flagship ₹499 plan lost ₹262 per subscriber. A redesign at the same price earns +₹154, with break-even at 440 subscribers. | Live Excel model, 54-person survey, deck |
| [Tata Motors](tata-motors/) | Segmentation took market share from about 5% to 14% (FY20–FY23). After-sales service is the threat; two sized fixes are worth about ₹70–120 Cr a year. | Report, 25-slide deck |
| [Adani vs Reliance](adani-vs-reliance/) | Reliance edges Adani 5–3 on a 10-metric ESG scorecard (2 even); each company's first fix identified. | 19-slide deck, scorecard |
| [GetawayGuru](getawayguru/) | 30.8% of 91 surveyed travellers cite "found a better deal" as a reason to cancel last minute, so offer rebooking credit, not cash refunds. | 91-person survey, deck, wireframes |
| [EPL transfer value](epl-transfer-value/) | Age, club rank, goals and minutes drive Premier League value; the model explains 68.4%. A replication of Li (2020). | Report, regression tables |
| [LinkUp](linkup/) | A 12-screen clickable prototype for joining local group activities. | Figma screens |
| [Hope for Recovery](hope-for-recovery/) | Secured a psychiatrist and hosted a live expert session for a student anti-substance-abuse campaign. | Strategy deck, content calendar, Instagram |

Team projects say so in their README, along with what I personally did.

Code projects live in their own repositories: football player detection, ESG sentiment classifier, Research Buddy, the shift-reduce parser, Autobot and Breakout.
